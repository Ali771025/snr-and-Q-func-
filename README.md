# SNR and Q-function Curves

MATLAB Q-function and error-probability curve examples across SNR and modulation orders.

## Overview

Three scripts plot logarithmic error-probability expressions over SNR ranges and compare different modulation-order parameters.

## Repository contents

- [LICENSE](LICENSE)

- [snr and Q func 2 .m](snr%20and%20Q%20func%202%20.m)
- [snr and Q func 3  .m](snr%20and%20Q%20func%203%20%20.m)

## Requirements

MATLAB; the scripts evaluate the Q-function through `erfc`.

## Getting started

Clone this repository and open its directory:

```bash
git clone https://github.com/Ali771025/snr-and-Q-func-.git
cd snr-and-Q-func-
```

Run the example from that directory:

```matlab
run('snr and Q func 1   .m')
% Also available: snr and Q func 2 .m and snr and Q func 3  .m
```

## Compatibility and scope

Parameters and axes are set inside each script. The files retain their original names, including spaces; use quoted filenames when running them.
